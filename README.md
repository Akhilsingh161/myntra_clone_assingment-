# Myntra Clone 👔

A beginner-friendly **Myntra-inspired fashion shopping homepage** built using HTML, CSS and JAVASCRIPT, featuring men's clothing, fashion banners, product sections, and category cards.

## ✨ Features

- Myntra-inspired navigation bar
- Search bar, Profile, Wishlist, and Bag sections
- Fashion sale banner
- Top brand deals section
- Men's fashion and clothing categories
- Product cards featuring shirts, T-shirts, jeans, and other men's wear
- Responsive layout for different screen sizes

## 🛠️ Technologies Used

- **HTML5** – Webpage structure
- **CSS3** – Styling and layout

## 📁 Project Structure

```text
myntra-clone/
├── index.html
├── style.css
└── README.md
```

## 🚀 How to Run

1. Download or clone the repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser or use Live Server.
4. Ensure an internet connection is available if the images use online URLs.

## 🎯 Project Purpose

This project was created for educational purposes to practice HTML, CSS, webpage design, product layouts, and responsive web development.
